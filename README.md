# Malody Web Editor（太鼓譜面エディタ）

ブラウザで動く、Malody 風の太鼓譜面（TJA）エディタです。スマホでもPCでも使えます。
作った譜面はその場でテストプレイできます。

## 使い方

### 開く・保存
- **☰ → .tja / .zip を開く**: `.tja` と音源を一緒に選ぶか、まとめた `.zip` を選択（中の `WAVE:` に合う音源を自動で組み合わせます）
- **音源を差し替え**: 新規作成した譜面に曲を付けるとき
- **.tja を保存 / .zip（譜面＋音源）**: 書き出し。`.tja` は UTF-8（BOM付き）
- 編集内容（譜面・音源）はブラウザ内に**自動保存**され、次に開いたときに復元されます

### 編集画面（Malody 風・横スクロール）
- Malody の太鼓エディタ（2000×924）の配置・大きさを画面の高さに合わせて再現
- ノーツは**左から右**へ並び、白い縦線が現在位置（再生位置）。上段に**音源の波形**、下段にイベント
- **横ドラッグ**でスクロール、**2本指ピンチ**または左上の六角形 −/＋ で拡大縮小、**波形をタップ**でその位置へ移動
- 左の六角形 ▶ で再生／停止（打音あり）
- 下のツールを選んで**レーンをタップで配置**。同じノーツをもう一度タップで削除、別の色なら置き換え
- **連打・風船**: 始点 → 終点の順にタップ。風船を風船ツールでタップすると打数を変更
- 右のアイコン: 元に戻す／やり直し／メトロノーム／テストプレイ／ファイル・保存／譜面情報／イベント／再生速度／分割

### テストプレイ
- 太鼓の達人のプレイ画面の配置（レーン・判定枠・左パネル・魂ゲージ）と演出（判定文字、光の粒、ノーツが弧を描いてゲージへ飛ぶ、コンボ太鼓、100コンボごとの巻物、音符文字、ゴーゴータイム）を再現
- 画像・キャラクター・効果音は公式素材を使わず、すべてオリジナルの描画
- 「譜面情報 → オート」をオンにすると自動で叩くので、譜面の確認に使えます
- 画面は太鼓の達人と同じ 16:9 で固定（余った部分は黒帯）。スマホでは画面のどこでもタップで叩けます。下の大きな楕円の面の中＝ドン、それ以外＝カッ。触れた場所に赤（ドン）／青（カッ）の波紋が出ます。終了ボタンは右上

### 判定
本家と同じ判定幅です（ずれの片側）。

| 判定 | 幅 |
| --- | --- |
| 良 | ±25ms |
| 可 | ±75ms |
| 不可 | ±114ms |

不可の幅より早く叩いたときは判定されず、遅れて 114ms を過ぎたノーツは見逃し（不可）になります。

- 叩いた色と同じ色のノーツのうち、叩いた時刻にいちばん近いもので判定します（1 つ見逃しても後のノーツがずれて判定されない）
- 色違いで叩いても不可にはせず、ノーツはそのまま残ります（TNDE / TJAPlayer3 と同じ）
- 大音符を叩いてから 50ms 以内の同じ色の 2 打目は「両手打ち」として扱い、次のノーツの判定には使いません（TNDE の BigNotesWaitTime と同じ）
- 連打・風船の最中に叩いた分は連打に入り、すぐ後のノーツの判定には使いません
- 叩いた瞬間の時刻（イベントの timeStamp）と、実際に聞こえている音の時刻で判定します

### 打音
- 「情報 → 打音ファイルを選ぶ」で自分の打音（例: dong.ogg / ka.ogg）を読み込めます。ファイル名に don が入っているものがドン、ka が入っているものがカッになります
- 読み込んだ音はその端末のブラウザの中だけに保存され、リポジトリには含めません（公式素材などを公開しないため）
- リポジトリの `public/sounds/` に `dong.ogg` / `ka.ogg`（mp3・m4a・wav も可）を置くと、全員の既定の打音になります（端末で読み込んだ音が優先）。公開リポジトリなので、配布してよい音だけを置いてください
- 内蔵の打音はオリジナルの合成音です

### 自動更新
- 新しい版が公開されると、起動時・アプリに戻ったとき・10分ごとの確認で自動的に読み直します（ホーム画面に追加し直す必要はありません）。テストプレイ中は終わるまで待ちます

### 画面の向き
- 常に横画面で表示します。端末を縦に持っているときは画面全体を 90° 回転させて横画面として表示します
- ホーム画面に追加すると、ブラウザのバーなしの全画面で使えます

### PC のショートカット
| キー | 動作 |
| --- | --- |
| Space | 再生 / 停止 |
| 1〜7 / 0・E | ドン・カッ・大ドン・大カッ・連打・大連打・風船 / 消去 |
| ← → | 1グリッド移動 |
| PageUp / PageDown | 1小節移動 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+ホイール, − ＝ | 拡大縮小 |

## 開発

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # パーサ・書き出し・zip・判定のテスト
npm run build   # dist/ に出力
```

`main` に push すると GitHub Actions がテスト → ビルド → GitHub Pages へ公開します
（Settings → Pages → Source を「GitHub Actions」に）。

## 構成

```
src/
  chart/    model.ts（編集用の拍ベース譜面・時間変換） tja.ts（読み込み） tjaWrite.ts（書き出し）
            types.ts（プレイ用の秒ベース譜面） decode.ts（Shift_JIS 対応）
  editor/   editor.ts（編集操作・Undo/Redo） view.ts（横スクロール画面・波形・タッチ操作）
  io/       zip.ts（依存なしの zip 読み書き） load.ts（ファイル読み込み） storage.ts（自動保存）
  play/     playmode.ts（テストプレイ）
  engine/   game.ts（判定・スコア）
  render/   renderer.ts（テストプレイの描画） notes.ts（ノーツ描画の共通部品）
  audio/    audio.ts（Web Audio）
  main.ts   画面の組み立て
```

譜面は内部では「秒」ではなく **tick（1拍 = 6720）** で持っています。BPM や OFFSET を後から変えても、ノーツが拍からずれません。

## 対応している TJA

`TITLE` `SUBTITLE` `BPM` `OFFSET` `WAVE` `DEMOSTART` `COURSE` `LEVEL` `BALLOON`（他のヘッダは保持して書き出し）
`#START` `#END` `#BPMCHANGE` `#SCROLL` `#MEASURE` `#DELAY` `#GOGOSTART` `#GOGOEND` `#BARLINEON` `#BARLINEOFF`

譜面分岐は現状「普通譜面（#N）」だけを読み込みます。

## 既知の制限

- iPhone / iPad の Safari は `.ogg` を再生できないことがあります。その場合は mp3 / m4a に変換してください
- 範囲選択・コピー＆ペースト、譜面分岐の編集、Malody 形式（.mc / .mcz）の読み書きは未対応

## 注意

既存の商用タイトルの名称・画像・効果音・公式譜面は同梱しないでください。
