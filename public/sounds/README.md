# 打音

このフォルダに次の名前で音のファイルを置くと、アプリの既定の打音になります（全員に適用）。

- ドン: `dong.ogg`（または `don.ogg` / `.mp3` / `.m4a` / `.wav`）
- カッ: `ka.ogg`（または `.mp3` / `.m4a` / `.wav`）

置かない場合は内蔵のオリジナル合成音を使います。
端末ごとに「情報 → 打音ファイルを選ぶ」で読み込んだ音があれば、そちらが優先されます。

※ このリポジトリは公開されているので、公式の効果音など、配布してよいか分からない音は置かないでください。
※ iPhone の Safari は .ogg を再生できないことがあるので、.m4a か .mp3 を置くと確実です（両方置いた場合は .ogg が優先されます）。
